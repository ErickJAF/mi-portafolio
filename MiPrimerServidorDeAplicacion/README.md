## Jerarquia del css

## De menor a mayor prioridad

1. Estilos del navegador (predefinidos)
2. Estilos del head (con <styles>)
3. Estilos de etiqueta (<p>)
4. Clases (.text)
5. Hojas de estilo externas (hojas .css)
6. Estilos en linea (adentro de la etiqueta con style)
7. !important (se pone en el estilo)
8. Media Queries (son como funciones)
